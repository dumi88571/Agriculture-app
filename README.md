## 📖 Overview

The **AI Agriculture Application** is a smart farming platform developed using **Python**, **Flask**, and **Machine Learning** technologies. The application is designed to assist farmers and agricultural organizations in improving crop productivity, monitoring soil health, predicting yields, and optimizing irrigation systems.

This project combines agriculture with modern AI-driven technologies to support sustainable farming practices and efficient farm management.

---

## ✨ Key Features

### 🌱 Crop Yield Prediction
Predict crop yield using:
- Historical agricultural data
- Weather conditions
- Soil characteristics
- Farming practices

### 🐛 Pest & Disease Detection
Detect crop diseases and pests at an early stage using image-based analysis and machine learning models.

### 💧 Smart Irrigation Optimization
Generate intelligent irrigation recommendations to:
- Reduce water wastage
- Improve crop health
- Increase farming efficiency

### 🌍 Soil Health Monitoring
Analyze soil nutrient levels and provide recommendations for soil improvement.

### ☁️ Weather Analysis
Monitor weather patterns and forecasts to help farmers make better planting and harvesting decisions.

### 📈 Market Price Prediction
Forecast crop market prices using predictive analytics and time-series data.

### ♻️ Sustainability Tracking
Track environmental impact and promote eco-friendly farming practices.

## 🧠 Machine Learning Models

The application uses several machine learning techniques, including:

- Random Forest Regression for crop yield prediction
- Classification models for pest and disease detection
- Clustering algorithms for soil analysis
- Time-series forecasting for market price prediction
- Rule-based irrigation recommendation systems

---

## 🗄️ Database Tables

The system uses SQLite with the following data models:

- **Farmers** → Farmer information
- **Farms** → Farm details and locations
- **SoilData** → Soil nutrients and composition
- **WeatherData** → Weather forecasts and conditions
- **CropData** → Crop growth and yield records
- **PestDiseaseData** → Disease and pest monitoring
- **IrrigationData** → Water usage management
- **MarketData** → Historical crop market prices
- **SustainabilityData** → Environmental impact metrics

## 🚀 Installation Guide

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/dumi88571/Agriculture-app.git
cd Agriculture-app
```

### 2️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 3️⃣ Activate the Virtual Environment

#### Windows
```bash
venv\Scripts\activate
```

#### Linux / macOS
```bash
source venv/bin/activate
```

### 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 5️⃣ Run the Application

```bash
python app.py
```
